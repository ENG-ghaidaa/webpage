# Full Stack Web Application

## Overview

This project is a simple full-stack web application built using:

- HTML
- CSS
- JavaScript
- PHP
- MySQL

The application allows users to add people information (name and age), store the data in a MySQL database, display records in a modern table, and update the status of each person instantly using AJAX (Fetch API).

---

# Features

## Frontend

- Clean and modern responsive UI.
- Centered form layout.
- White background design.
- Rounded input fields.
- Modern typography and spacing.
- Smooth hover animations.
- Modern table design.

## Form

The form contains:

- Name input field
- Age input field
- Submit button
- View Database button

Validation is applied before submitting the data.

# Backend

The backend is developed using PHP.

Features:

- MySQL database connection.
- Prepared statements for secure data insertion.
- Separate PHP files for better organization.
- AJAX requests using Fetch API.
- Dynamic table updates.
